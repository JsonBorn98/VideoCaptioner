## Shoals
- [后处理宽 except Exception 会把停止当成对齐降级](videocaptioner/core/postprocess/runner.py) — timing_resolver 和 run_post_stage 外包的 except Exception 会吞掉 InterruptedError，把主动停止记成对齐降级或模块级失败；取消必须先于 Exception 单独放行并发布 cancelled。
- [postprocess 扫描钩子的宽 except 须先放行 InterruptedError](videocaptioner/core/postprocess/__init__.py) — run_post_stage 里新增的只读扫描钩子照搬了模块惯例 except Exception——会吞 InterruptedError 把主动停止记成跳过；新钩子必须先 except InterruptedError: raise 再接宽 except（与 runner.py 既有 shoal 同型）。
- [Windows 路径不能用 sha256: 作目录名](videocaptioner/core/postprocess/workspace.py) — 输入指纹是 sha256:hex，冒号在 Windows 上不能出现在路径分量里；任务过程目录只用 hex，完整指纹只写进 manifest。
- [except OSError 会吞掉 InterruptedError](videocaptioner/core/postprocess/workspace.py) — InterruptedError 是 OSError 子类；except OSError 或 except Exception 都会把主动停止当成文件不可读。读盘前必须先 except InterruptedError: raise。
- [Qt 子进程测试偶发 0xC0000005 崩溃](tests/test_ui/test_postprocess_interface.py) — tests/test_ui 里经 _run_qt_script 起 PyQt5 子进程的测试在全量套件里偶发 Windows 访问违例崩溃（returncode 3221225477、stdout/stderr 全空）——失败不指向被测代码，先单独重跑该文件再判断，别按真回归排查
- [duck-typed config 契约：方法 vs property](videocaptioner/core/postprocess/translation.py) — 把工厂函数（snapshot_from_subtitle_config 按属性契约调用 config.effective_translation_mode()）喂新 config 类时，effective_translation_mode 必须是方法不是 property——写成 @property 工厂调用 str() 直接炸 'str object is not callable'，pyright 不报（鸭子类型），只有跑测试才红；造 config 代餐时逐属性核对原契约是方法还是 property
- [bash -m 提交信息里的模板变量会被替换](videocaptioner/core/prompts/split/sentence.md) — git commit -m "...${segment_target_cjk}..." 在 Git Bash 里炸 bad substitution——双引号字符串里的 ${...} 是变量替换；commit message 要提模板变量语法时一律用 git commit -F - 配引号定界 heredoc（<<'MSGEOF'），别走 -m 双引号
- [输入指纹跨 SRT 落盘不稳定（float/int 序列化漂移）](videocaptioner/core/postprocess/workspace.py#L108 fingerprint_subtitle) — workspace 身份指纹对内存 ASRData（float 时间戳）和落盘重载的 SRT（int 时间戳）算出不同哈希，翻译阶段若按内存数据预算 task_dir、后处理按重载字幕验证 manifest，同一输入会被判身份不符而拒绝复用。接线翻译→workspace 前必须先定指纹归一化契约（如按毫秒取整），并注意改归一化会让旧 manifest 指纹全部失配。
- [只验证工作区消费者会漏掉独立翻译产物交接](tests/test_postprocess/test_translation_to_postprocess_handoff.py) — 人工验收后两条真实runner交接测试稳定失败：强化翻译仍在普通输出目录写旧三件套，不创建workspace/manifest；独立后处理仅查身份目录清单，缺checkpoint与translation_snapshot。防止复发须覆盖真实翻译产物→初版SRT→全新后处理任务，不以预填manifest或内存explicit_assets代替；仅搬文件不足以修复。本次仅诊断，尚未修复。
