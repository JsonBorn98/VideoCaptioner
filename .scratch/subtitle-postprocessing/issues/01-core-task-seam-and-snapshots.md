# 01: 建立核心后处理任务切面与不可变快照

**What to build:** 让后处理通过一个核心任务入口接收规范字幕、布局、冻结配置和可注入依赖，统一发布活动字幕、报告、警告及下游继续状态。任务开始时保存不可变初版快照，模块级失败可以安全回退。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [ ] 核心任务入口可以处理内存字幕和外部字幕，并发布一致的任务结果。
- [ ] 任务开始时保存完整初版快照，后续处理不修改输入数据或输入文件。
- [ ] 配置在任务开始时冻结，运行过程不受设置页面后续修改影响。
- [ ] 无效初版、模块级异常、取消和正常完成分别产生可区分状态。
- [ ] 模块级失败时活动字幕回退到完整初版，结果包含警告和下游是否继续的信息。
- [ ] 核心行为通过 fake gateway、时间证据和资产适配器可测试，不依赖 Qt 或 CLI 输出。
