# 03: 建立过程资产目录与 manifest 发现

**What to build:** 让独立后处理在输入视频或字幕旁使用 ASCII 的 `videocaptioner-workspace` 过程资产目录，按规范化任务名、输入指纹和语言对隔离任务，保存并验证上游过程资产。缺失或不可信资产必须明确报告，并支持显式备用输入。

**Blocked by:** 01

**Status:** resolved

- [ ] 独立任务会创建或复用输入旁的 `videocaptioner-workspace`，不会把过程文件散落到普通输入输出目录。
- [ ] 任务目录身份包含规范化任务名、输入字幕指纹和语言对，互不相撞。
