# 02: 迁移每侧观看约束与长度验收

**What to build:** 让后处理独立负责原文侧和译文侧的显示长度策略。每侧支持单行限长或自动换行；单行侧使用折算字符数、中文/英文目标与绝对上限及混合语言有效阈值，自动换行侧跳过长度和行数约束但保留其他后处理能力。

**Blocked by:** 01

**Status:** resolved

- [ ] 原文侧和译文侧可以独立选择两种显示模式，默认均为单行限长。
- [ ] 折算字符数按已确认权重计算，空白及零宽格式字符不增加长度。
- [ ] 中英文目标上限和绝对上限具有正确的排序校验，目标上限不高于绝对上限。
- [ ] 混合语言字幕根据内容占比选择有效阈值。
- [ ] 自动换行侧不产生长度或行数问题，播放器负责最终换行和渲染。
- [ ] 单行侧超出绝对上限会形成可供修复规划消费的问题，回退区域不会被记为通过。
