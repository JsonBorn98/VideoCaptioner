# 05 - 高级校对批量化与依赖调度

**构建什么.** 让增强型后处理把容量允许的多个合格修复主体共同交给高级校对，在保留必要校对、独立身份和逐项验收的前提下减少逐主体请求。主修复到对应校对的依赖保持，不同主体链可重叠执行，不等待整轮主修复全部完成才启动任何校对。

依据本 feature 规格的高级校对容量与候选版本决策、ADR-0019/0020/0021。校对读取修复轮次快照叠加对应主候选的明确视图，边界上下文不读取邻批刚完成的结果；稳定输入分组避免网络完成顺序改变批次语义。校对角色独立计算完整载荷预算与输出预留，保留主体、片段和错误的独立映射。

不为凑满批而无限等待，允许容量不足或单主体的小批；不减少校对覆盖、不增设全片校对、不改模型及推理配置。校对失败保留已经合格的主修复候选并明确告警，不能标记校对成功；同批其他合法校对项独立验收。复用完整任务入口及01冻结基准，真实模型质量验证留给08另行授权。
