# 04 - 审计检查点与审计级恢复

**构建什么.** 作为字幕制作者，翻译质量审计跑到一半中断时，重跑不用再付一遍全文校对请求。

每个审计批完成后写入该批的结构化审计问题，批以其覆盖的字幕段编号集合为键，登记进恢复 manifest 的级别④（先写数据文件再更新 manifest）。恢复时按当前配置重新规划审计批：键完全匹配的批直接采用已保存的问题、零请求，其余批重跑；全部批到齐后自动修复客观问题或人工审计确认照常一次进行，报告内容与不中断运行等价。翻译批处理上限等配置漂移使审计批规划变化时，键不匹配的批自然重跑，不做部分匹配推断。审计检查点不含模型原始响应，只存结构化问题。遵守 ADR-0022。

**阻塞于.** 02

**状态.** ready-for-agent

- [ ] 审计中途中断后重跑：已完成审计批零请求、未完成批重跑，翻译审计报告与不中断运行等价
- [ ] 人工审计确认在全部审计批到齐后触发且只触发一次；自动修复客观问题路径结果与不中断运行一致
- [ ] 审计批键为字幕段编号集合；批规划变化时不匹配的批重跑，不复用部分结果
- [ ] 审计检查点损坏或缺失时该级视为未完成并告警，任务继续
- [ ] 主动停止发生在审计阶段时已完成审计批保留并登记在 manifest
