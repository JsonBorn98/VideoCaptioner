# 05 - 翻译配置漂移与恢复溯源标注

**构建什么.** 作为字幕制作者，我改了提示词或换了模型后重跑，恢复提示要告诉我哪些配置和检查点当时不一样，成果里也能查到这次是恢复运行、哪些部分受漂移影响，而不是静默复用或直接作废。

恢复 manifest 记录冻结配置摘要：主翻译提示词哈希、高级校对提示词哈希、主翻译模型配置方案（方案名、模型、接口类型）、高级校对模型配置方案、翻译批处理上限、边界语境段范围。恢复时逐项比对生成漂移清单进恢复摘要（替换 02 的占位）；任何漂移都不作废检查点（宽松口径，ADR-0022）。恢复过的运行在翻译执行快照与过程资产 manifest 写入恢复来源（检查点时间、恢复时已完成级别）与漂移清单；翻译审计报告新增一节标注漂移项与受影响成果（如“部分译文来自旧提示词”）。漂移比对逻辑与恢复摘要类型模块无关，供后处理票（07）复用。
