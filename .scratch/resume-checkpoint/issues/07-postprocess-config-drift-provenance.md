# 07 - 后处理配置漂移与 QA 报告/状态溯源

**构建什么.** 作为字幕制作者，我换了后处理配置方案（模板或自定义方案）或翻译角色配置后重跑后处理，恢复提示要列出与检查点当时不一样的配置，QA 报告和后处理状态也能查到这次是恢复运行、受哪些漂移影响，而不是静默复用或直接作废。
