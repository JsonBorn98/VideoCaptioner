# 03 - 翻译简报文件与全文分析级恢复

**构建什么.** 作为字幕制作者，全文分析完成后才中断（术语阶段或更晚），重跑同一源字幕时不用再付一遍全文分析请求。

分层全文分析（窗口分析 + 汇总）完成后，把翻译上下文简报与去重后的疑难术语候选写成翻译简报文件：资产种类 context 重新加入种类表并定义带版本的 schema（简报全部字段；候选的词形、义项、出现字幕段编号、别名、代表语境所需引用），登记进恢复 manifest 的级别①（先写数据文件再更新 manifest）。恢复时级别①已完成则跳过全文分析零请求，直接以文件内容进入术语阶段与完整翻译提示词组装；由文件驱动的提示词与不中断运行完全一致。

模块成功发布时，翻译简报文件与权威术语表、翻译审计报告、译文检查点一起复制进任务过程目录并登记过程资产 manifest；后处理过程资产发现把 context 作为上游资产按 JSON 可读性验证并复制，本轮不新增消费者（D07 简报复用维持未确认）。它不随项目术语表文件导出。遵守 ADR-0022。

**阻塞于.** 02

**状态.** ready-for-agent

- [ ] 术语阶段中断后重跑：全文分析窗口与汇总零请求，术语阶段与后续照常，成果与不中断运行等价
- [ ] 翻译简报文件有 schema 与版本标识；损坏或版本不符时告警、视级别①未完成并重跑全文分析
- [ ] 以文件恢复的简报与候选喂出的完整翻译提示词与不中断运行逐字一致（主 seam 测试用假网关记录请求比对）
- [ ] 成功发布后任务过程目录含 context 资产且过程资产 manifest 登记；后处理过程资产发现验证并复制它，其余种类行为不变
- [ ] 翻译简报文件不含 API key、完整 prompt、模型原始响应；不进入项目术语表文件
