# 06 - 后处理阶段末/轮末检查点与恢复

**构建什么.** 作为字幕制作者，后处理在观看问题修复的第 N 轮之后中断（失败、主动停止、崩溃），对同一初版字幕重跑时前 N 轮不再发请求，尝试计数、已关闭区域、回退记录延续，最终后处理字幕、QA 报告与后处理状态和不中断运行等价。

复用 02 的恢复 manifest 与「恢复决定」回调形状，检查点身份 = 输入指纹 + 语言对。检查点作为瞬时资产种类登记进任务过程目录的 manifest。阶段末检查点在确定性阶段、压缩重译、语义修复完成、进入观看问题修复前写入（工作字幕全量 + 质量报告累积状态：阶段报告、压缩失败、速度结果、精确时间轴结论）；轮末检查点在修复轮次归并验收后写入（工作字幕全量 + 修复摘要：轮次号、请求计数、各问题身份尝试计数、已关闭区域、回退记录、下一轮反馈、候选与状态指纹）。修复循环通过完成回调把轮末状态交给运行器、由资产库落盘，修复循环自身仍零磁盘 I/O，ADR-0021 的冻结上下文与确定性归并不变。

恢复在过程资产发现之后、进入处理之前读取 manifest；决定继续时装载工作字幕与累积状态，跳过前处理与后处理阶段直接进入修复循环并恢复计数器；业务修复重试上限、轮次上界、连续传输失败上界以恢复的计数继续。模块成功时按现有「未再产生的种类除名并删除」规则清理；主动停止与模块级失败保留（停止仍不交付部分成果、阻断下游、迟到结果不写回）；分析模式不写；仅报告流程只写阶段末。精确时间轴证据不进检查点。阶段摘要输出「从恢复检查点继续」一行。本票不含后处理配置漂移比对与 QA 报告溯源标注（由 07 交付）。遵守 ADR-0022。

**阻塞于.** 02

**状态.** ready-for-agent

- [ ] 第 N 轮归并后中断重跑：前 N 轮零请求，尝试计数、已关闭区域、回退记录延续，最终后处理字幕、QA 报告、后处理状态与不中断运行等价（后处理模块入口 seam 测试）
- [ ] 阶段末中断后恢复不重跑压缩重译与语义修复请求
- [ ] 主动停止后检查点保留、无交付、下游阻断；模块级失败后保留；成功后检查点文件删除且 manifest 除名，过程资产导出不含
- [ ] 分析模式不写检查点；仅报告流程只写阶段末
- [ ] 输入指纹不同不发现检查点；manifest 损坏告警并从头；未提供回调默认继续，回调返回从头则 manifest 重置
- [ ] 修复循环无新增磁盘 I/O（落盘经运行器与资产库）；既有轮次快照归并、并发、取消、持久化与导出测试全部通过
- [ ] 阶段摘要含「从恢复检查点继续」行
