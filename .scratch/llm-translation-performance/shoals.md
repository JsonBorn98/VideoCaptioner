## Shoals
- [Concurrent gateway delay keys collide across stages](tests/test_translate/test_enhanced_orchestrator.py) — Integer delay keys are cue IDs shared by analysis/translation/audit; gate delays with delayed_stages or a later-stage cancel test will stall on translation delays.
- [ScriptedGateway is not thread-safe](tests/test_translate/test_enhanced_orchestrator.py) — Existing ScriptedGateway tests stay valid only because profile clamp keeps concurrency at 1; concurrent coverage must extend ConcurrentScriptedGateway, not invent a new double.
- [on_translations must accept partial ID maps](videocaptioner/core/translate/enhanced/runner.py) — Runner accumulates by subtitle ID then writes. Incremental _translated_copy must not require full coverage; only the final success path still does.
- [execute_batches on_complete is coordinator-thread](videocaptioner/core/translate/enhanced/batch_executor.py) — Checkpoint merge and progress belong in on_complete so they stay thread-safe. Do not fire them from worker execute().
- [progress callback is (int, str) not a list sink](videocaptioner/core/translate/enhanced/orchestrator.py) — progress signature is (int, str); list.append cannot be passed as the callback.
- [ThreadPoolExecutor.shutdown(cancel_futures=True) 只取消排队任务，不取消在途请求](videocaptioner/core/split/split_by_llm.py + videocaptioner/ui/thread/subtitle_thread.py（stop 路径）) — 踩坑：给线程池 stop() 调 shutdown(wait=False, cancel_futures=True) 后以为已停——它只取消还没开始的 future，正在跑的 LLM 请求继续执行；agent-loop 反馈步和 gateway 重试还会发新请求，强杀进程时 threading._shutdown 卡在 join() 上打出 KeyboardInterrupt。避开：停止必须三件套——(1) 把 cancelled 回调传进 LLMGateway.complete 让重试循环立即退出，(2) except Exception 前先放行 InterruptedError 否则取消信号被当失败重试，(3) run() 阶段边界加 raise_if_cancelled 门。
- [裸 except Exception 吞掉 InterruptedError：取消被包装成「检查 API key」](videocaptioner/core/optimize/optimize.py + videocaptioner/core/translate/base.py + videocaptioner/core/translate/llm_translator.py（裸 except Exception 路径）) — 踩坑：把 cancelled= 回调接进 gateway.complete 后，gateway 停止时会抛 InterruptedError——但消费模块里既有的裸 except Exception（optimize.py 三处、base.py 翻译两处、llm_translator.py 一处）会把它当普通失败吞掉：optimize 误计 failed_batches、base.py 更糟——fail_rate≥0.5 会把用户取消包装成 RuntimeError("Check your API key and network connection")。避开：给消费 gateway 的模块接 cancelled= 时，必须同步在它向上传播路径上的每个裸 except Exception 前加 except InterruptedError: raise；review 规则：新接 cancelled= 的 diff 必须检查调用链上全部 except Exception。
