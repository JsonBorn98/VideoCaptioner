# 字幕后处理独占观看约束并批量修复问题字幕

2026-09-05 用户确认：翻译优化仅负责内容准确性、语义完整性和校订，所有观看用长度限制、显示分段与阅读体验调整统一归属后处理；初版保留完整内容但不保证显示限长，从而消除上游与后处理重复或互相破坏约束的职责混杂。

后处理绝对保留原文字句，仅允许拆分；译文可按观看要求重译。修复以问题区域为主体，并像上游翻译批次一样向上下扩展边界上下文，范围直接复用上游 `boundary_context_radius` 设置；汇集批量处理，拼接后重新验收并重试剩余问题。第一次提交属于正常流程，失败后默认最多进行 4 次业务重试，耗尽时局部恢复原字幕、报警并记录未解决问题，也允许用户选择仅报告人工处理。网络级重试不占用业务重试次数；上游同类业务重试也采用相同口径。自动换行模式跳过后处理的长度和行数约束，交给播放器或下游渲染器。旧观看长度和原文改写配置全部删除，不做迁移。独立后处理默认从输入资产旁的 `videocaptioner-workspace` 专用过程目录发现并验证上游资产，缺失时允许用户显式补充。

该决定替代 ADR-0002 中初版承担完整观看交付保证的解释，以及 ADR-0001 中允许显式开启原文改写的选择；两份 ADR 中关于独立成果保存、后处理可选和双语结构对应的原则保留。后处理受约束重译应按原翻译方式选择角色，原工具角色配置通道不能决定此项重译是否执行高级校对。

这是已确认的设计方向，运行代码尚未迁移；批量请求容量、翻译资产快照字段、时间分配、计数口径的具体迁移位置等未决细节见[持续设计记录](../dev/subtitle-postprocessing-design-record.md)。
