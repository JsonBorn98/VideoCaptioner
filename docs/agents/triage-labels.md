# Triage 标签

技能用五个标准 triage 角色说话。这个文件把这些角色映射到本仓库 issue tracker 实际用的标签字符串。

| mattpocock/skills 里的标签 | 本 tracker 的标签 | 含义 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估这个 issue  |
| `needs-info`               | `needs-info`         | 等报告者补充更多信息 |
| `ready-for-agent`          | `ready-for-agent`    | 已完全规约，可交给 AFK agent  |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现            |
| `wontfix`                  | `wontfix`            | 不会处理                     |

当技能提到某个角色（比如「打上 AFK-ready triage 标签」）时，用这张表里对应的标签字符串。
